Conventions

Conventions

The words, the files and their suffixes, how to name scans so that the core reads them, the units, the versions and ids. The same tables close every manual as its Appendix A; the files come from the project's file dictionary, the table the core itself names its files by.

Words

word what it means
plot set Several data files shown together; each is a member, with its value of the set’s variable.
member One pattern of a plot set: a file (or one scan of a file of several), its value of the variable and its source.
variable What orders the members and places them on the map: a temperature, a time, or a value typed with its source.
source (of a value) Where a value comes from: a file’s header, its name, its title, a temperatures file, or a note typed with it. Every value keeps one.
second variable Another value per member (the temperature of a scan in a set against time), shown on the map’s right-hand axis.
proposal A plot set the core finds in a folder: by temperature, a hold against time, the whole run against time.
hold Three or more scans at the same temperature, followed against the time since the first of them.
exposure class Scans counted alike, told apart by the core from the scale of their counts (the median of σ²/y above 2°): long and short scans fall in different classes.
rebin The points of a scan averaged onto a coarser regular grid (0.01°) by the core as the set opens; the files are untouched.
x interval The interval of 2θ a set is cut to as it opens (x_interval = [from, to] in its set file): every view, window and map then works on the cut set; the files are untouched.
clip The colour range chosen on the colour bar inside the core’s full range; values beyond it are drawn saturated.
region A named rectangle of a map (2θ and variable), with its own colour range, saved with the set.
window A range of 2θ whose quantities (integral above the background, centroid, strongest peak) the Series view follows through the set.
reference member The member subtracted in the Difference Map and in the Linked zoom’s difference strip.
view rule Normalise… or Convert X…: a change of how the set is drawn; the files are never changed.
live set A set opened from a proposal that grows with the new scans live mode finds in the folder.
the core diff-ref-struct’s engine (Rust), here compiled to WebAssembly: it computes every number the page shows.

Files and suffixes

The project’s own kinds come from its file dictionary (the same table that names the files the core writes); the others are files the page meets.

name or suffix kind what it holds where
{original} Measured data The measured pattern(s) as the instrument wrote them, never changed. Data/
{data} processed.xys Data after the operations The scan after the control file’s data operations (masks, smoothing, rebinning, …): x, y, σ. Data/
{set} {operation}.xys Derived pattern of a plot set The sum, average or difference of members of a plot set on a common grid, with σ, its ‘!’ lines naming the members, each with its value of the series variable and the source of that value (Plots’ PL9). Plots/
{set}.drv Plot set Several data files as one set (Plots’ PL12): the members (each file relative to the project’s folder, a scan, a value of the series variable typed or read from a temperatures file, with its source (PL23), visible, opacity, colour), the variable’s name and unit, the x quantity, the y scale, the order, the displacement rule, the reference member, the windows; the views’ steps and scales, the normalisation (PL27); the map’s and the difference map’s colour range as clipped by the user (map_range, difference_range), and the regions of the variable–x plane saved by name ([[regions]]: x with the quantity it was drawn in, the variable’s range, a colour range of its own, the window it came from) (PL37). Plots/
{name}.drp Publication set What a document of the Publish module holds (R30, L094): the source (control file, version, results file), the sample’s facts the files cannot give, and the figures, tables and CIFs with their options, built from those sources only (publish/DESIGN.md §5). Publish/
{project}.drc Control file The refinement: the pattern and its data file, the phases and their atoms (or symmetry modes), what is refined, the cycles, the conventions. A joint refinement’s (P06, L329): its patterns’ control files (pattern_control) with their weights, refined flags and phases, the phases’ names, and the parameters the patterns share ([[joint.pattern]], [[joint.phase]], [[joint.tie]]). the project’s folder
{original} The app’s state What the app keeps about the project: the versions’ metadata, the open windows, the last run (L067, L080). .drs/
.buf WinPLOTR buffer A list of data files with a value each, written by FullProf’s WinPLOTR; opens as a plot set, its files taken from its folder.
.xye, .xy, .dat, .xys, .qye, .chi, .gsas, .xrdml, .ras, .cif … Data files Read by the core’s readers by their content first, their extension second (Manual §21).
the address after # A view link folder, set, view, scale, zoom, clip, region of the view shown: names and numbers, never a file’s content (Manual §16).

Naming scans

The core places a scan without help when its name says the temperature or the time. A sequence number first keeps the folder in acquisition order. Examples are file names the core reads as shown.

in a name the core reads
_300K, T300, 1p5K a temperature in K (1p5K is 1.5 K)
T0900C, 900C, 900°C a temperature in °C; a set whose every value is in °C stays in °C
t16530s the elapsed time in seconds (a lower-case t before the seconds)
_long, _short words only: the core finds exposure classes from the counts, not from the name
scan_001_T0900C_t00000s_long.xye sequence, temperature, time, exposure: sortable and read by the core

On this page

    What this is

    The site of diff-ref-struct Web, a browser tool for many powder diffraction patterns at once. The numbers are computed by the diff-ref-struct core, compiled to WebAssembly and run in your browser; your files are read there and never uploaded. The tool is the Plots module of the diff-ref-struct Mac app for Rietveld refinement.
