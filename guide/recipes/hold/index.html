A hold: growth curves

A hold: growth curves

Scans repeated at one temperature: follow a phase's reflections through time, as integrals above the background with their σ, and find the first scan where each one is real.

You havethree or more scans at the same temperature, the time of each in its name or in a set file You getfor each reflection, its integral against time with σ; the onset at 3σ; regions of the map ViewsMap, Series, Overlay with Linked zoom

Open the hold against time

The core finds holds by itself (the hold at 1270 °C: 39 scans against time, 166.433 min …). In this version, though, a proposal against time opens with each scan's temperature as its variable, so all the rows of a hold sit at one temperature and the map collapses (Versions). Until that is fixed, open the hold from a plot set file (.drv) that types each scan's time:

  1. A .drv already made (in the Mac app, with drs, or by a colleague): put it in the folder's Plots/, with the scans where it names them (usually Data/ beside Plots/), open the folder and double-click it. Its members open at their times, each with its source (minutes since the first scan of the hold, from the elapsed seconds in the scan's name).
  2. Write one: a .drv is plain text. This short script, run in the folder that holds Data/ and Plots/, writes one for the scans of a hold whose names carry the set point and the elapsed seconds (…_T1270C_t16530s_…), each scan's time in minutes since the first with its source: 
    python3 - > Plots/hold.drv <<'EOF'
import glob, re
fs = sorted(glob.glob("Data/*_T1270C_*.xye"))
first = int(re.search(r"_t(\d+)s", fs[0]).group(1))
print('format = "drs plot set 1"\ntitle = "the hold at 1270 °C"\nvariable = { name = "t", unit = "min" }\nx = "2theta"\nrebin = 0.01\n')
for f in fs:
    s = int(re.search(r"_t(\d+)s", f).group(1))
    print(f'[[member]]\nfile = "{f}"\nvariable = {{ value = {(s - first) / 60:.2f}, source = "minutes since {fs[0].split("/")[-1]}, from the elapsed seconds in the names" }}\n')
EOF
    Change T1270C to your hold's tag. To leave a beamstop's first degree out of the whole analysis, add x_interval = [0.5, 27.0] after rebin = 0.01 (from 1.1.0). Checked on a hold of 39 synchrotron scans: the page opens it with t from 0 to 166.43 min.
  3. For large scans, the line rebin = 0.01 (written by the script above; add it under the first line of any other .drv) makes the core average each scan onto a 0.01° grid as it opens (the files untouched), and the map draws in a fraction of a second. On a hold of 39 synchrotron scans of 27 000 points: 2699 columns, the core's range 0–28.3 √counts, opened in about 5 s.

Steps

  1. Map, colour √, and a clip that quiets the background. Read upwards in time: a reflection growing is a stripe brightening row by row.
  2. Choose clean reflections. A reflection that sits on another phase's peak will give a curve of both. Zoom on each candidate and check, in the Overlay with Linked zoom, that its neighbourhood is flat in the first scans.
  3. Series, + window for each: a name ((113)), and From and To about one peak width either side of its centre. Narrow windows (±0.025° at 0.001° steps, 50 points) follow one line; wider ones take its tails and more background noise.
  4. quantity integral above the background, background line between the ends for a line on a smooth background, automatic (arPLS) for one on a curved background.
  5. Read the curves: each point is a scan, its σ bar the core's; open points are below 2σ. The onset is the first scan whose integral stands above 3σ and stays there.
  6. Name the map's regions for the record (Save region…), and Save Plot Set: the windows, regions and clips go into the .drv, which the Mac app and drs read.

What to watch for

  • Background. A straight line between the window's ends is the plainest background and the easiest to state; it differs from a background taken from flanking windows, so integrals from two methods differ while onsets should agree.
  • The time's origin. Say what t = 0 is: the hold's first scan, the run's first, the moment the set point was reached. A set file says it in each value's source.
  • Overlapping phases. If no reflection is clean, follow two and say which overlaps what.

On this page

    What this is

    The site of diff-ref-struct Web, a browser tool for many powder diffraction patterns at once. The numbers are computed by the diff-ref-struct core, compiled to WebAssembly and run in your browser; your files are read there and never uploaded. The tool is the Plots module of the diff-ref-struct Mac app for Rietveld refinement.
