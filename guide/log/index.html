L435 · Core 0.82.0: the x interval of the analysis set once and kept by the set file, every member cut to it on opening (PL42); drs-wasm follows the app’s W9 (patterns, rebin)

2026-10-26 · work

The order of L434 for the core. - SetFile::x_interval (x_interval = [from, to], in the set file’s x quantity; absent by default): read (a pair in order, refused backwards), written only when given, described (“the analysis cut to 2theta 2 to 20 on opening: every member’s points outside it left out, the files untouched”). - PlotSet::cut(interval, quantity): every member keeps its points from from to to and only those, its facts (points, range, step) the cut scan’s. The interval is converted to a member’s own x with its file’s λ when the set file’s quantity is another, as a region’s bounds are (PL37), and refused by name when a λ is lacking. A member left with fewer than two points inside is refused by name (“its range, 21 to 27, does not reach the x interval 2 to 20”). A set cut again keeps the narrower interval. PlotSet keeps x_interval (and the quantity it is in), so SetFile::of writes it back. - Applied on opening: - SetFile::open* apply the file’s interval before its rebin (W9). - open, open_from and open_buf keep their signatures: their callers cut on opening (drs plots, drs-wasm, and the app’s bindings once Plots adds the argument). - propose(files, x_interval) cuts each file as it reads it, so the facts are the cut scans’ and every proposal’s set file carries the interval; a file the interval leaves without points is named. - Every function of plots then works on the cut set with no change of its own (the grid, map, difference map, displacements, projection, series, derive, CSV, page_data), with one exception, windows: a window outside the interval is refused as such (“window "beamstop", 0.5 to 1.5, lies outside the analysis’s x interval 2 to 20”), where without the check it would fail on no points. - drs plots … --x-interval a:b on every plots command that opens a set (on a .drv, in its x quantity, after its own interval; save writes it; propose gives it to its proposals). - drs-wasm: - plots_open_from, plots_open_buffer_from, plots_open_set_from and plots_propose take xInterval: [a, b]; files added to a cut set are cut alike; save writes the interval. - The commands test found the app’s plots_rebin (Plots’ step 22) missing: ported. On this page

    What this is

    The site of diff-ref-struct Web, a browser tool for many powder diffraction patterns at once. The numbers are computed by the diff-ref-struct core, compiled to WebAssembly and run in your browser; your files are read there and never uploaded. The tool is the Plots module of the diff-ref-struct Mac app for Rietveld refinement.
