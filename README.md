# diff-ref-struct Web

Powder diffraction data as plot sets in the browser: the diff-ref-struct core compiled to WebAssembly, the app's Plots module, your files read in the browser and never uploaded. Live at <https://jmigartua.github.io/diff-ref-struct-web/>.

The built site only (web 24d8619, core 0.81.0, 2026-10-25), published by an Action of the private repository diff-ref-struct; every run replaces it whole. Third-party licences: LICENCES.md.
