# core

The refinement engine of diff-ref-struct, in Rust (design question Q1, decided in L021). One crate, `drs`:
a library that the Tauri app links directly, and the `drs` command-line program. Its one dependency, `serde` (with
`serde_json`), is behind the `serde` feature, on by default, which writes and reads the model as text (L058);
`cargo build --no-default-features` builds the core with no dependency at all.

## Rules

- No UI imports, ever. The app draws what the core returns.
- Every feature has a named test and a path from the `drs` command line. A feature is claimed (on the site,
  in the release notes) when its named test passes.
- Tests compare against independent sources: FullProf's own output files in `manuals/fullprof/`, the
  International Tables, spglib. A number typed from memory is not a reference.
- Each refinement cycle is reported as an event (`lsq::Cycle`: parameters with shifts, shift/esd and esd's, λ, notes, Ycal, agreement
  factors) so that the app can draw it live (design question Q5).
- Python is the scripting interface, through bindings to this crate, in version 2 (P48). No physics in Python.

## Conventions

- Lengths in Å, angles in degrees at every interface; radians only inside functions.
- Reciprocal quantities without the factor 2π: for an orthogonal cell a* = 1/a, and 1/d² = hᵀ G* h.
- Direct metric tensor G with G_ij = a_i · a_j; reciprocal metric G* = G⁻¹.
- Cartesian frame as FullProf's: x along a, y in the ab-plane, z = x × y. The crystal-to-orthonormal matrix
  M has a, b, c as its columns (r_cart = M · r_frac).
- Busing–Levy B matrix (Acta Cryst. 22 (1967) 457): h_cart = B · h, upper triangular.
- Matrices are `[[f64; 3]; 3]`, row-major: `m[i][j]` is row i, column j.
- Symmetry operators are general operators {R|t} acting on fractional coordinates, x' = R·x + t: R an integer
  matrix, t in twelfths of a lattice vector, reduced to 0…11. Products {R1|t1}{R2|t2} = {R1R2 | R1t2 + t1}.
  Written as coordinate triplets, "-x+1/2,y,-z+1/2", as FullProf and CIF write them.
- Space groups come from Hall symbols (Hall 1981; International Tables Vol. B, ch. 1.4), with the change of
  origin as {I|V}{R|t}{I|−V}. Point groups use the International Tables' class symbols ("-42m", "-6m2", "-3m").
- Anisotropic displacements are FullProf's betas, exp(−hᵀβh), ordered β11 β22 β33 β12 β13 β23; on a site they obey
  R·β·Rᵀ = β. The U_ij of a CIF obey the same relations (no rotation of a conventional setting mixes axes of
  different length; test `u_ij_follow_beta_relations`).
- Constraints are linear relations over free parameters, value_i = c_i + Σ a_ik·p_k, exact in rationals; the free
  parameters are variables themselves, the earliest ones in the order x y z or β11 … β23 (as FullProf picks them).
- Reflections transform as row vectors, h' = h·R. A reflection is absent when an operator {R|t} has h·R = h and h·t
  not an integer. The unique reflections are chosen as FullProf (CrysFML `Hkl_Uni`) chooses them: the member of each
  set of equivalents (Friedel mates included) inside the loop's index box and FullProf's region for the Laue class;
  lists are sorted by decreasing d, then h, k, l.
- Structure factors sum over all the operators of the group (centring and inversion included):
  F(h) = Σ_j Occ_j f_j(s) exp(−B_j s²) Σ_g T_jg exp(2πi h·(R_g x_j + t_g)), s = sinθ/λ = 1/(2d), with T_jg the betas of
  the image, exp(−(h R_g) β (h R_g)ᵀ). Occ is FullProf's (manual p. 102): chemical occupancy × m/M, m the multiplicity
  of the site and M of the general position, so that each position counts once; a CIF's occupancy is converted.
  |F|² is what FullProf prints as F² in its `.hkl` files: f′ and f″ included, the overall B not.
- Scattering: X-ray form factors f(s) = Σ a_i exp(−b_i s²) + c (electrons) by species, ions included ("Ti+4", "O-2");
  f′ and f″ of the element at the anode (Cr, Fe, Cu, Mo, Ag) whose Kα1 is nearest to λ, as CrysFML and FullProf take
  them; neutron coherent scattering lengths of the element in 10⁻¹² cm. Tables: CrysFML's.
- The default model and FullProf's rules (`powder::Convention`, L043, L046, L050). The papers in `manuals/papers/`
  set the default, or FullProf's manual where no paper sets a rule; `Convention` holds, rule by rule, whether
  FullProf's rule is followed instead. Importing a `.pcr` (`Model::from_pcr`, the app, `drs calc`) translates its
  values, refined under FullProf's rules, into the default model wherever the translation is exact, and keeps
  FullProf's rule only where none exists (L047, L050); `Model::from_pcr_fullprof` (the FullProf tests,
  `drs calc --fullprof`) keeps the values as written under all of FullProf's rules.

  | Rule | Default (source) | FullProf | Import |
  |---|---|---|---|
  | X-ray Lorentz–polarisation | manual eq. 3.26, K = ½ | twice that (L033) | scale × 2 |
  | Bérar–Baldinozzi | F_b = (8u³ − 12u)e^{−u²}, u > 0 below 2θ_h (B&B 1993, eqs. 12–15, pp. 128–129) | F_b = (4u² − 3)F_a (L035) | P1 + 3P2, P3 + 3P4 |
  | axial divergence | S/L, H/L as given (FCJ 1994, eqs. 4, 5, 9, p. 895) | D_L < 0.0002 read as (H/L + S/L, H/L − S/L) (CrysFML) | `profile::fullprof_axial` |
  | exponential preferred orientation | b + (1 − b)exp(−Gα²) (Dollase 1986, Table 1, no. 5) | exp(+G1 α²) (manual eq. 3.31) | G1 → −G1 |
  | excluded points | those within the regions | also those a step away (L033) | regions snapped to the data's points |
  | peak window | ±Wdt·FWHM (manual p. 75) | without X tan θ, one more low point if X ≠ 0 (L035, L042) | kept: no exact translation |
  | reflections used | every one whose window reaches the data | to `reflection_limit`, or 5° past the last point (L035) | kept: no exact translation |
  | microstructure output | β* with each reflection's λ (microstructure paper, eq. 14), no strain for U < 0 | λ1, √|U| (L039) | default (output only) |
  | sample displacement | Sycos·cos θ (manual eq. 3.37, p. 56) | Sycos·cos 2θ (its `.prf` ticks and `.sub` profiles, L267) | kept where Sycos ≠ 0: no exact translation |

  Unchanged because the papers and FullProf agree: the Bérar–Baldinozzi sign (FullProf's, the paper's; the manual's
  eq. 3.29 prints the opposite), the TCH (H, η) (Thompson, Cox & Hastings 1987, eqs. 2–3, p. 80), the Caglioti widths
  (eq. 11, p. 225), March–Dollase averaged over the equivalent reflections (Dollase eq. 4 and no. 6, p. 268; March
  1932, p. 291). Test `default_convention`: the default's formulas and the identities the import uses (`default_rules`);
  every FullProf run imported reproduces its χ² under FullProf's rules exactly, and the change when the two kept rules
  are also switched to the default is frozen per run (`pcr_import`).
- Powder patterns (constant wavelength) are calculated from FullProf's manual (pp. 41–58) and, where the manual is
  silent, from CrysFML (commit 8ed8670) or from FullProf's own files:
  y_i = b_i + Σ_φ S_φ Σ_h L_h |F_h|² Ω(2θ_i − 2θ_h) (eqs. 3.1–3.2), with the position 2θ_h + Zero + Sycos·cos θ +
  Sysin·sin 2θ (pp. 56–57); Ω a pseudo-Voigt (Npr = 5) or TCH pseudo-Voigt (Npr = 7) normalised to unit area, widths
  from U V W IG (and X Y for TCH, eqs. 3.16–3.17), the resolution file's U V W X Y Z added, all evaluated at the
  Bragg angle without Zero and the displacement terms (FullProf's `.out` widths agree only so, L039); the overall B as
  exp(−B_ov|h|²/2) on |F|² (p. 58); Finger–Cox–Jephcoat asymmetry by CrysFML's `Prof_Val` at every angle below AsyLim;
  Bérar–Baldinozzi asymmetry (Bérar & Baldinozzi 1993, conventions above), applied on top of FCJ when a phase has both
  (L042);
  preferred orientation (eqs. 3.31–3.32) averaged over the reflections equivalent to h, as FullProf's CORR shows (L042)
  and GSAS-II computes it (`GSASIIstrMath.py`, `GetPrefOri`); absorption (eqs. 3.33–3.34). A parametric resolution
  file (Res = 1–3) brings its wavelengths and Ratio (WAVE) and Cthm (CTHM), which replace the `.pcr`'s, and its axial
  divergence (ASYM S_L D_L), which is added to the phase's (L042): rules of FullProf's input, not in its 2001 manual.
  Neutron Lorentz factor 1/(2 sin²θ cos θ). λ2 adds peaks only when Ratio ≠ 0 and λ2 ≠ λ1. In excluded regions FullProf's
  profile is the background alone, and at the last point of the pattern too (its `.prf`; the tests allow for it).
  Each peak is calculated over ±Wdt widths about 2θ_h (manual p. 75); with FullProf's convention, CrysFML's `Locate`
  sets the range (L042), and the rutile-anatase and MgAl2O4 windows and the YVO3 window at Wdt = 40 still differ, by a
  rule not found (frozen). FullProf generates reflections past the last point as far as its `.out` prints (S(1/d)max,
  by a rule not found): `Phase::reflection_limit` takes it.
  Profile matching (Jbt = 2) takes the intensities of `CODFILn.hkl` as they are, without the scale factor.
  Agreement factors use the weights of Iwg: 1/σ² (0), maximum likelihood 1/σ²_calc (1, manual p. 43), unit (2).
- Size and strain (`microstructure`) as FullProf's `.mic` files give them: from the phase's U, X (strain) and I_G, Y
  (size) and the resolution file, through the TCH (H, η) and the integral breadth of the pseudo-Voigt; apparent size
  D = 1/β*, maximum strain e = ½β*d (× 10⁴), β* in Å⁻¹ (conventions above).
  Anisotropic size and strain (LorSiz, size and strain models, Str) are version 2 and refused with a message.
- Parameters take their names and documentation from the parameter dictionary, `ecosystem/data/parameters.yml`
  (L044, L046): 45 entries; `parameter_table` is generated from it by `ecosystem/tools/build.py` (do not edit it by
  hand), and `parameters::FIELDS` maps every field of `Model`, `Phase` and `Atom` to its ids. The data operations'
  settings are described the same way in `ecosystem/data/operations.yml` (L088), from which `operation_table` is
  generated.
- FullProf's runs with NCY = 0 still make one cycle (L035): their profile, widths and breadths belong to the values
  read (`CODE.pcr`); the tick marks of the `.prf` are the Bragg angles of those values shifted by the Zero after the
  cycle, and the apparent sizes and strains of the `.mic` are those of the values after the cycle (L039).
- Data and model files named in a `.pcr` are looked for in its folder, its parent and the parent's folders
  (`pcr-files/` next to `Data-files/`), then the grandparent and its folders; a Windows path keeps its last part only.
- A position is on a symmetry element when the operator maps it within 0.001 (fraction of a lattice vector) of
  itself; `drs site --tol` changes this.
